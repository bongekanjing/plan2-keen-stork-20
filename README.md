# Merged-Fix Bounties: A 30-Day Agent Plan

An agent-ownable month of claiming stalled-fix bounties on algora.io, shipping the patch, and getting paid on merge.

## The plan

Sell merged fixes: $50-500 algora.io bounties; maintainers pay on merge. Day 1: filter bounties whose linked PR stalled 7+ days, claim one, fix it, pass repo tests, open a PR. Edge: stalled PRs are pre-diagnosed; run 5 at once on $20 API credits. Realistic month one: $300-900.

## Run it

    MAKEFUN_OUTPUT_DIR=out python3 main.py

Writes the plan to out/entry.txt and prints its character count (277).
